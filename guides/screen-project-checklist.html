Field note 35 / Measurements

Prepare a multi-window rescreening project

Track panels, rolls, spline and installation order before cutting.

Editorially prepared 15 November 2026

The decision you need to make

A household screen project becomes inefficient when similar panels are mixed up or one roll is cut before the biggest pieces are planned. A measured panel list reduces waste and helps you test material choices on one low-risk opening first.

What to inspect first

  • Create a label for every window and record the screened opening plus outer-frame dimensions separately.
  • Group identical mesh products and retention profiles; do not combine incompatible spline specifications in one shopping row.
  • Inspect frame condition and hardware before deciding that every panel only needs new fabric.

A practical sequence

  1. Use the Panel Notebook to record each opening, material and repair note.
  2. Run the Mesh Cut Planner for the working fabric rectangle, then use the Roll Layout Estimator for batches of matching panel sizes.
  3. Calculate approximate spline length using each groove perimeter, then check manufacturer packaging and diameter.
  4. Test one frame end-to-end before cutting all remaining panels from the roll.

Worked situation

You have six window panels but two are 1.1 m tall and four are 0.7 m tall. Plan the tall cuts first, then see whether the smaller pieces fit useful offcuts; the identical-panel estimator is only a starting point.

Common wrong turn

Buying one spline diameter for every frame based only on color, or cutting a roll without labeling the panels, creates avoidable rework.

When to stop:

For large or inaccessible screens, arrange a professional installation assessment rather than bundling them into the same DIY plan.
