Measurement method

Exactly which measurements are used by our calculators and why.

Cut rectangle

Cut width = screened-opening width + 2 × selected overlap. The same formula applies to height. Overlap is an editable working allowance for handling and trimming mesh, not the final replacement-frame tolerance. Some manufacturers recommend different overlaps for different assemblies.

Roll length estimator

For N identical cut rectangles, we compute pieces across the roll as floor(roll width ÷ cut width), and rows as ceil(N ÷ pieces across). Roll length is rows × cut height, plus the user-defined reserve. We repeat after rotating each piece by 90 degrees and select the smaller valid estimate. This is a simple straight-row packing model: it is not optimized nesting for assorted panel sizes and does not account for roll defects or unusable remnants.

Spline length

Perimeter = 2 × (groove width + groove height). We multiply by number of identical panels and by (1 + reserve percentage / 100). This only estimates length. Diameter and cord compatibility depend on groove dimensions, screen thickness and the manufacturer’s specifications.

Measurements to keep separate

Outside-frame width is for fitting an entire replacement frame; screened-opening dimensions are for a mesh cut; groove path dimensions are for spline length. Mixing them up causes preventable ordering errors. For irregular paths, measure directly and consult the product documentation.
